# agent-sync

Sync AI agent instructions from a single `.ai/` source of truth to every major coding-agent framework.

Write instructions once. Run one command. Get output for **Cursor**, **GitHub Copilot**, **Claude Code**, **Gemini**, **Continue**, **OpenCode**, **Kilo**, and **Antigravity**.

## Install

```bash
git clone https://github.com/unum-io/agent-sync.git
cd agent-sync
pip install -e .
# or with uv
uv tool install .
```

Requires Python 3.11+. No runtime dependencies (stdlib only, uses `tomllib`).

## Quick start

```bash
# 1. Add source files
mkdir -p .ai/instructions .ai/commands

cat > .ai/manifest.toml <<'EOF'
[[instructions]]
name = "general"
file = "instructions/general.md"
description = "Core directives"
always_apply = true
EOF

cat > .ai/instructions/general.md <<'EOF'
You are a helpful pair programmer. Minimize scope and match existing style.
EOF

# 2. Sync to all frameworks
agent-sync

# 3. Preview without writing
agent-sync --dry-run

# 4. CI check
agent-sync --check
```

See [examples/minimal/](examples/minimal/) for a complete example.

## Configuration

Optional `.ai/config.toml`:

```toml
project_name = "MyApp"
frameworks = ["copilot", "cursor", "claude", "gemini", "continue", "opencode", "kilo", "antigravity"]

[opencode]
watcher_ignore = ["node_modules/**", "dist/**"]
```

> **Migrating from YAML:** earlier versions read `manifest.yaml` / `config.yaml`.
> These are no longer supported; agent-sync exits with an error if it finds them.
> Rewrite each list item under `instructions:` / `commands:` as an
> `[[instructions]]` / `[[commands]]` table with quoted string values.

| Field | Default | Description |
|-------|---------|-------------|
| `project_name` | repo directory name | Title in `CLAUDE.md` and `AGENTS.md` |
| `frameworks` | all | Limit which frameworks get output |
| `opencode.watcher_ignore` | generic ignores | Patterns for `opencode.json` watcher |
| `write_opencode_json` | `true` | Generate `opencode.json` |
| `write_kilo_json` | `true` | Generate `kilo.json` |

## Generated file locations

| Framework | Instructions | Commands |
|-----------|-------------|----------|
| **Copilot** | `.github/copilot-instructions.md`, `.github/instructions/*.instructions.md` | `.github/skills/*/SKILL.md`, `.github/prompts/*.prompt.md` |
| **Cursor** | `.cursor/rules/*.mdc` | `.cursor/commands/*.md` |
| **Claude** | `CLAUDE.md`, `.claude/rules/*.md` | `.claude/skills/*/SKILL.md` |
| **Gemini** | `.gemini/rules/general.md`, `.gemini/skills/*/SKILL.md` | `.gemini/skills/*/SKILL.md`, `.agents/workflows/*.md` |
| **Antigravity** | `.agents/rules/*.md` | — |
| **Continue** | `.continue/rules/*.md` | — |
| **OpenCode** | `AGENTS.md`, `.opencode/rules/*.md`, `opencode.json` | — |
| **Kilo** | `.kilo/rules/*.md`, `kilo.json` | `.kilo/command/*.md` |

Every generated file includes an `AUTO-GENERATED by agent-sync` header.

## Git hooks

Warn after `git pull` / `git merge` when instructions are out of sync:

```bash
agent-sync install-hooks
```

## CLI reference

```
agent-sync [--repo-root PATH] [--source-dir .ai] [--dry-run] [--check]
agent-sync install-hooks
```
